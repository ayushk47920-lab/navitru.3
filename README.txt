NAVITRU - SIMPLE HOSPITAL ASSISTANCE WEBSITE

PAGES
1. index.html   - Home page
2. patient.html - Patient token search, department selection and room directions
3. admin.html   - Demo admin login, queue settings, doctor directory and appointment records

TECHNOLOGY
- HTML5
- CSS3
- Vanilla JavaScript
- Browser localStorage for demo queue settings and appointment records

HOW TO RUN
1. Extract the ZIP file.
2. Open the final1 folder.
3. Double-click index.html (or right-click and open with Chrome/Edge).
4. Use the Patient and Admin links in the top navigation.

IMPORTANT
This is a front-end class project demonstration. It does not connect to a real hospital, database, map, GPS, or live appointment service. Data is saved only in the current browser using localStorage. Do not enter real patient information.
